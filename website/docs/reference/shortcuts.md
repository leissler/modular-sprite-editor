# Keyboard and mouse

On a Mac, **Cmd** is the Command key. On Windows and Linux, use **Ctrl** wherever this page says Cmd. The editor
shows the same list under **Help ▸ Keyboard & Mouse Shortcuts**.

Shortcuts only reach a canvas when you are not typing in a text field. Click the canvas first if a key does nothing.


## Global

| Action | Shortcut |
| --- | --- |
| Undo / Redo (all editors) | Cmd+Z / Cmd+Shift+Z |
| New / Open / Save / Save As | Cmd+N / Cmd+O / Cmd+S / Cmd+Shift+S |
| Switch tab | Cmd+1 to Cmd+6 |
| Preferences | Cmd+, |
| This help | Cmd+/ |

## Every canvas

| Action | Shortcut |
| --- | --- |
| Zoom at cursor (smooth, settles on whole pixel sizes) | Mouse wheel / two-finger scroll / pinch (View ▸ Scroll Moves the View: pinch / Cmd+scroll) |
| Pan | Space+drag, Alt+drag or middle-drag |
| Pan horizontally / vertically | Shift+wheel / Alt+wheel (Scroll Moves the View: scroll) |
| Zoom in / out | Cmd+= / Cmd+- |
| Fit content / actual pixels (1×) | Cmd+0 / Cmd+Shift+0 |
| Toggle grid | Cmd+G |
| Console colours (View menu) | Cmd+Shift+P |

## Modules

| Action | Shortcut |
| --- | --- |
| New module (on an image) / shape (on Shapes) | Drag on empty space |
| Select / move / resize | Click / drag a module / drag a handle |
| Add or remove from the selection / select with a marquee | Cmd+click / Cmd+drag |
| Move pivot (Shift is taken here) | Shift+drag (or the inspector's presets) |
| Nudge selected modules 1 px / 8 px | Arrows / Shift+arrows |
| Copy / Paste (onto any image) / Duplicate / Select all | Cmd+C / Cmd+V / Cmd+D / Cmd+A |
| Rename / reorder modules | Double-click or F2 / drag in the list |
| Delete selected modules | Delete / Backspace |
| Cancel picking the key colour / clear the selection | Esc |

## Frames

| Action | Shortcut |
| --- | --- |
| Select / add / add or remove / cycle stacked parts | Click / Shift+click / Cmd+click / click again |
| Select with a marquee | Drag on empty space (Shift or Cmd adds) |
| Nudge selection 1 px / 8 px | Arrows / Shift+arrows |
| Flip horizontal / vertical | H / V  (X / Y also work) |
| Rotate 90° CW / CCW | R / Shift+R |
| Draw order forward / backward | Cmd+↑ / Cmd+↓  (Shift = to front / back) |
| Copy / Paste / Duplicate / Select all | Cmd+C / Cmd+V / Cmd+D / Cmd+A |
| Delete selection | Delete / Backspace |
| Add a part | Drag from the library onto the stage, or double-click it (adds at the origin) |
| Nest a frame | Drag it from the frames list or the library onto the stage |
| Rename / reorder frames | Double-click or F2 / drag in the list |
| Clear the selection | Esc |

## Animations

| Action | Shortcut |
| --- | --- |
| Play / pause | Enter |
| Previous / next step | , / .  (← / → in the sequence) |
| Previous / next tick | Shift+, / Shift+. |
| First / last step | Home / End |
| Shorter / longer hold of the selected steps | [ / ]  (or drag a step's right edge) |
| Flip horizontal / vertical, rotate selected steps | H / V, R / Shift+R |
| Move the selected steps' offset 1 px / 8 px | Arrows / Shift+arrows (stage focused), or drag the stage |
| Select steps / range / add or remove | Click / Shift+click / Cmd+click (Shift+← / → in the sequence) |
| Reorder / copy steps | Drag a step / Alt+drag |
| Insert a frame | Drag from Frames into the sequence or onto the stage, or double-click it |
| Copy / Paste / Duplicate / Select all steps | Cmd+C / Cmd+V / Cmd+D / Cmd+A |
| Delete selected steps | Delete / Backspace |
| Open a step's frame in the Frames tab | Double-click the step |
| Rename / reorder animations | Double-click or F2 / drag in the list (list order) |
| Zoom / scroll the step sequence | Wheel / Shift+wheel or trackpad sideways (Scroll Moves the View: Cmd+wheel / wheel) |

## Timeline

| Action | Shortcut |
| --- | --- |
| Play / pause | Enter |
| Previous / next frame | , / .  (← / → in the timeline) |
| Previous / next key of the selected layer | Shift+, / Shift+. |
| First / last frame | Home / End |
| Set key at playhead / add-or-remove key | K / Shift+K |
| Flip horizontal / vertical, rotate the selected layers | H / V, R / Shift+R |
| Nudge the selected layers 1 px / 8 px | Arrows / Shift+arrows (stage focused) |
| Select layers: a range / add or remove | Shift+click / Cmd+click a layer name |
| Select layers on the stage | Shift+click / Cmd+click, or drag on empty space (Shift or Cmd adds) |
| Delete selected keys (else the layers) | Delete / Backspace |
| Copy / Paste / Duplicate / Select all keys | Cmd+C / Cmd+V / Cmd+D / Cmd+A |
| Copy / Paste layers (also into another scene) | Cmd+C / Cmd+V with layers but no keys selected |
| Rename / reorder / delete scenes | Double-click or F2 / drag / Delete in the Scenes list |
| Select keys / add / add or remove / box-select | Click / Shift+click / Cmd+click / drag empty track |
| Retime keys / add key | Drag keys / double-click track |
| Segment easing, swap image, layer menu | Right-click bar / key / layer |
| Reorder or parent a layer | Drag the layer name (onto a layer = make child) |
| Zoom / scroll time, scroll layers | Wheel / Shift+wheel or trackpad sideways, wheel over layers (Scroll Moves the View: Cmd+wheel / sideways / wheel) |
